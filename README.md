# Setup for Contribution

You must have a github account, first. You can make one for free.
Before you go asking for contributor, please consider making a Pull Request, as its a lot simpler, and I personally see it. It basically compares your code to the code in this repository, and I can approve a merge of that code into this repository.

If you're just edting the wiki file or the bugs file, you can just click the little edit buttons here on the github website to edit the files in-browser. Simple.

If you do not know how to merge/pull, I suggest you watch videos before executing anything. Please do not mess up the repository, your contributor will be removed and you will be given a punishment ingame and in the discord.
